Character Planner for The Division 2

Run character-planner.exe to open the planner. Keep data and licenses beside the executable.
No Go, Node, Python, or source checkout is needed to run this release.
Windows requires a graphics driver supporting OpenGL 2.0 or newer.
Builds are saved in your user configuration directory under character-planner.
Attribution, artwork credits and modeling limits: docs/ATTRIBUTION.md.
To validate the included catalog: character-planner.exe --check-packs
Testers: docs/IN_GAME_CHECKLIST.md lists the in-game readings that settle open values.

Scripts and agents: run planner.exe --help. It reads the bundled pack, lists the catalog,
resolves and compares builds without a window, and controls a running planner window
through its session commands (for example: planner.exe --json session inspect).
See docs/CLI.md for commands, edit operations, exit codes and the session protocol.
